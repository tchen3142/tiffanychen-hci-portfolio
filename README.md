# Tiffany Chen — HCI Portfolio

A lightweight HTML/CSS/JavaScript portfolio website featuring two collaborative human-centered design projects, research documentation, and a developing HCI research interest.

## Featured projects

### [Lumo — Helping Mothers Be Heard in Healthcare](projects/lumo/README.md)
Human-centered healthcare communication concept developed in a five-person team (2022), exploring language barriers, patient autonomy, and translating clinical conversations. **Tiffany's contribution:** Storyboarding and video production. The [case study includes a storyboard narrative visual](projects/lumo/README.md#storyboard-evidence-communicating-the-patient-experience). Includes an [interactive Figma prototype](https://www.figma.com/proto/u36ZD4vPvIeuyycDGgbgHn/Prototype?node-id=103%3A41&scaling=scale-down&page-id=0%3A1&starting-point-node-id=103%3A41&show-proto-sidebar=1), [final team video](https://youtu.be/TUtkYGcVBCk), a [research/process summary](projects/lumo/design-process.md), and original class presentations.

### [Accessible Payment App Redesign](projects/payment-redesign/README.md)
Collaborative usability research and proposed redesign of digital payment workflows (2022). **Tiffany's contribution:** User interviews and usability testing. The [case study maps anonymized findings to design opportunities](projects/payment-redesign/README.md#research-evidence-observations-and-design-implications). Includes a [research/process summary](projects/payment-redesign/design-process.md) and the [final team presentation](Seminar%20in%20Human%20Factor%20Design/Final%20Redesign%20Presentation.pptx).

## Portfolio website

- `index.html` — website structure
- `styles.css` — design and layout
- `script.js` — renders project cards and profile links
- `config.js` — editable name, contact information, and project cards
- `projects/` — individual case studies, summaries, and some project files

To publish via GitHub Pages, use **Settings → Pages → Deploy from a branch → main → /(root)**. The expected project URL is `https://tchen3142.github.io/tiffanychen-hci-portfolio/` once publishing is enabled.

## Working with the archive

Lumo's original team assets are now organized in `projects/lumo/` under **Recordings**, **Interviews Conducted**, **Prototypes**, **Storyboards**, **Research and Planning**, **Meetings and Planning**, and **presentations**. The two curated case studies live under `projects/`. Some larger presentations are linked to their [original project repository](https://github.com/tchen3142/IEME4200FinalProject), because the connected transfer could not copy every binary file automatically.

**Privacy & authorship:** Both projects were completed by teams. Team credits appear in each project README. Research notes include named interview participants and should be reviewed or redacted before sharing the repository as a public admissions portfolio. The case studies do not claim that these concepts were deployed or clinically validated.
